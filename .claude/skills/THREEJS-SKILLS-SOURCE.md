# Three.js skills

From https://github.com/CloudAI-X/threejs-skills (MIT). They document modern
three.js (r160+ ESM). The live try-on in this project is pinned to r131 globals
because of the WebAR.rocks helper, so check the API exists in r131 before using
their examples there; the <model-viewer> storefront bundles a modern three.js.
